# NORMA Design Code

Дизайн-код NORMA в виде скила для Claude Code: токены, полотно, навигация, блоки, движение, адаптив, правила и чек-лист приёмки. Эталон - [primeglow.co/moloko](https://primeglow.co/moloko).

## Установка

```bash
git clone https://github.com/lvsiba-pixel/norma-design-code ~/.claude/skills/norma-design-code
```

Обновить:

```bash
git -C ~/.claude/skills/norma-design-code pull
```

## Состав

- `SKILL.md` - описание скила, карта документа и короткая выжимка правил
- `references/NORMA_DESIGN_CODE.md` - полный дизайн-код
